# Remote

**Definició:** Un remot és una versió del repositori que està guardada a un altre lloc (normalment a GitHub) i que té un nom curt per no haver d'escriure tota l'adreça. Serveix per enviar-hi i baixar-ne commits amb `push`, `fetch` i `pull`.

**Exemple:** Amb `git remote -v` es veuen els remots configurats i la seva adreça. Després de fer un fork i clonar-lo, se sol tenir `origin` (el teu fork) i es pot afegir l'original amb `git remote add upstream https://github.com/GuillemMas87/glossari-git.git`.

**Relacionat amb:** origin, clone, push, fork
